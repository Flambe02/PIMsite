# PIM V2 - Spécifications Mobile-First

## 🎯 Vue d'ensemble

Version 2.0 de PIM avec architecture mobile-first, focus CLT & PJ.

## 📱 Écrans cœur (CLT & PJ)

### CLT (Salariés)
- **Money Found** - Découverte d'économies potentielles
- **Portabilidade** - Portabilité des benefits
- **Explain Payslip** - Explication des bulletins de paie

### PJ (Prestataires)
- **Tax Center** - Centre fiscal et optimisations
- **Provas e Economias** - Preuves et économies
- **Explain PJ** - Explication du statut PJ

## ✅ Critères d'Acceptation

- [ ] Interface mobile-first responsive
- [ ] Navigation intuitive entre CLT/PJ
- [ ] Calculs fiscaux précis (±1%)
- [ ] Performance < 3s sur mobile
- [ ] Accessibilité WCAG 2.1 AA

## 📊 Analytics

- Funnel de conversion CLT vs PJ
- Temps passé par écran
- Taux d'engagement des recommandations
- Métriques de performance mobile

## ⚖️ LGPD

- Consentement explicite pour chaque traitement
- Droit à l'oubli implémenté
- Audit trail complet
- Chiffrement des données sensibles

## 🚀 Performance Budgets

- **LCP < 2.5s** (mobile)
- **INP < 200ms**
- **CLS < 0.1**
- **JS initial < 170KB gz**
